# Agentic-AI
This repository demonstrates the implementation of Agentic AI — an AI system designed to autonomously understand goals, plan multi-step workflows, interact with tools/APIs, and execute tasks with minimal human intervention.

Agentic AI → You give goal → It plans → Executes → Checks → Improves → Completes

This system is built using:

Planner Agent – Breaks down user goals

Executor Agent – Executes steps using tools

Evaluator Agent – Reviews and improves output

Tool Layer – External functions (search, calculator, etc.)
